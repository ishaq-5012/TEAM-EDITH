Institution application input packages

Four institution accounts are covered. Each college folder has one institution.txt and twelve application folders. Each application folder has input.txt and every checklist PDF.
The PDFs are institution-prepared records, not letters or certificates issued by a regulator.
Harborview PDFs carry an intact digital signature, certificate chain, offline revocation record and timestamp from a locally configured institution signing system. This establishes local file integrity and the configured signing identity; it does not establish approval or authenticity from an external authority.
Use authorized issuer sources for external approval and affiliation checks.
